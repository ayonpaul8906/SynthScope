# SynthScope

**SynthScope** is an AI-powered synthetic user research platform that helps teams validate product ideas by generating realistic virtual personas and simulating user research.

The platform enables users to create synthetic personas based on a target audience, interact with them through surveys or conversations, and gather AI-generated insights to support product decisions.

## Tech Stack

* Frontend: React + TypeScript
* Backend: Python (FastAPI/Flask)
* Database: PostgreSQL
* AI: Google Gemini / OpenAI
* Styling: Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/SynthScope.git
```

Navigate to the project directory:

```bash
cd SynthScope
```

Install dependencies and start the development server according to the frontend and backend setup.
